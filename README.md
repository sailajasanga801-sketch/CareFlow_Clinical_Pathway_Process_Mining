# CareFlow: Clinical Pathway Process Mining

## Project Overview
CareFlow is a healthcare process mining project that analyzes patient treatment pathways using event log data.

## Objectives
- Explore healthcare event log data.
- Understand patient treatment pathways.
- Identify variations in clinical processes.
- Analyze patient journey patterns.
- Visualize process insights.

## Dataset
Sepsis Cases Event Log.

## Technologies
- Python
- Pandas
- Process Mining
- Data Visualization
- Git and GitHub

## Project Status
Initial setup completed. Dataset files collected. Development in progress.
